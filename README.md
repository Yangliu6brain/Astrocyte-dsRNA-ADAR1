# **Astrocyte-Specific dsRNA–ADAR1 Signalling Links Innate Immunity to Complement Activation in Parkinson’s Disease**

This repository contains the R pipeline that reproduces all snRNA-seq analyses and figures in the manuscript, from per-dataset quality control through the eight-module gene-scoring framework, cell-type coupling analyses, and robustness checks.

Funded by the Aligning Science Across Parkinson’s [000497, 020505, 027228] through the Michael J. Fox Foundation for Parkinson’s Research and the National Health and Medical Research Council of Australia to GMH [Investigator Grant 2034292]

------------------------------------------------------------------------

## 1. Overview of the pipeline

The analysis re-uses three public snRNA-seq datasets of human cortex, merges and integrates them, adds donor covariates, then runs a series of donor-level (pseudobulk) analyses built on an eight-module gene-scoring framework (ADAR1, ADAR2, SNCA, dsRNA_Processing, dsRNA_EV_Transport, dsRNA_Sensing, Innate_Immune, TE_Control).

```         
GEO raw data  ->  per-dataset QC  ->  merge + integrate + annotate + covariates
                                                    |
                                                    v
                                Script 1  (module scores + CX_8Module_AllResults.rds)
                                                    |
        +-------------+--------------+--------------+--------------+---------------+
        v             v              v              v              v               v
    Script 2      Script 3       Script 4       Script 5       Script 6      Script S1
     (fGSEA)   (module x immune) (A1 Fisher Z) (immune PD vs   (Braak)     (sensitivity)
                                                  Control)
```

Scripts 2, 3, 4, 5, 6 and S1 all consume `CX_8Module_AllResults.rds` and the covariate-annotated cell-type RDS objects produced upstream.

Analyses were run in **R version 4.4.3**. Key packages:

| Purpose | Packages |
|------------------------------------|------------------------------------|
| Single-cell handling | Seurat (v5.4.0), SeuratObject, Matrix, SingleCellExperiment |
| Integration / QC | harmony (1.2.4), scDblFinder |
| Differential expression | DESeq2 (1.46.0) |
| Pathway enrichment | fgsea (1.32.4), msigdbr |
| Stats / wrangling | dplyr, tidyr, tibble, stringr, ppcor |
| Output / plotting | openxlsx, ggplot2, patchwork, pheatmap, ggrepel, RColorBrewer |
| Path handling | here |

Exact versions for the run used in the manuscript are recorded in `sessionInfo.txt` at the repository root. Each script additionally writes a `session_info.txt` into its own output folder at runtime.

## 4. Data availability

This study re-analyses three publicly available snRNA-seq datasets of human cingulate cortex:

| Accession | Notes                                       |
|-----------|---------------------------------------------|
| GSE202210 | flat 10x files                              |
| GSE178146 | —                                           |
| GSE253462 | donor age provided as ranges; midpoint used |

Download the raw matrices from GEO into `data/raw/<ACCESSION>/` before running. **No raw or individual-level data are redistributed in this repository.**

Donor covariates (age, sex, post-mortem interval) are defined in Section 12 of `Full_merge_RDS_script_with_covariates.R`. All values are taken from the public GEO records / original publications.

## 5. How to run

All scripts resolve paths relative to the repository root via the **here** package — no absolute paths need editing. Set the dataset/region flags at the top of each script where indicated. Run from the repository root.

**Step 1 — Quality control** (run once per dataset). Writes `GSE*_merged_step1.rds` plus QC plots and per-sample QC summaries into `data/`:

``` r
source("R/GSE_202210_Step1_Seurat_UPDATED.R")
source("R/GSE_178146_Step1_Seurat_UPDATED.R")
source("R/GSE253462_Step1_Seurat_UPDATED.R")
```

**Step 2 — Merge, integrate, annotate, add covariates.** Reads the three `GSE*_merged_step1.rds` from `data/` and writes the covariate-annotated cell-type objects (`CX_Astrocytes_withCov.rds`, `CX_Neurons_Total_withCov.rds`, etc.) into `data/`:

``` r
source("R/Full_merge_RDS_script_with_covariates.R")
```

**Step 3 — Core module analysis:**

``` r
source("R/Script1_Combined_8Module_DESeq2_Analysis_V1_Final.R")
```

This writes a timestamped output folder containing `CX_8Module_AllResults.rds`. **Copy that file into `data/`, keeping the name `CX_8Module_AllResults.rds`**, so the downstream scripts find it.

**Step 4 — Downstream analyses** (run after `CX_8Module_AllResults.rds` is in `data/`):

``` r
source("R/Script2_Unified_ModuleRanking_fGSEA_KEGG.R")
source("R/Script3_Module_x_Immune_Correlation.R")
source("R/Script4_A1_FisherZ_Specificity.R")
source("R/Script5_PD_vs_Control_Immune_Panels.R")
source("R/Script6_Braak_Analysis.R")
source("R/Script_S1_Module_Sensitivity_Analysis.R")
```

A fixed random seed is set at the top of every script for reproducibility (`set.seed(42)`; Script 5 and Script S1 use `set.seed(2026)`).

## 6. Script-to-manuscript mapping

| Script | Produces | Manuscript figure/table |
|------------------------|------------------------|------------------------|
| `GSE_*_Step1_Seurat_UPDATED.R` | Per-dataset QC, doublet removal, UMAP_by_condition | *Suppl. A* |
| `Full_merge_RDS_script_with_covariates.R` | Integrated, annotated, covariate-enriched cell-type RDS | *Suppl. B* |
| `Script1_Combined_8Module_DESeq2_Analysis_V1_Final.R` | Pseudobulk DE (PD vs Control), module scores, cross-module partial-Spearman correlations, SNCA cross-cell-type, TE_Control coupling | *Figure 4, Suppl. Fig 1* |
| `Script2_Unified_ModuleRanking_fGSEA_KEGG.R` | Module-driven gene ranking + fGSEA/KEGG, astrocyte vs neuron enrichment | *Figure 8* |
| `Script3_Module_x_Immune_Correlation.R` | Module × 9 immune sub-panel partial-Spearman + Fisher-Z cell-type comparison | *Figures 5, 6* |
| `Script4_A1_FisherZ_Specificity.R` | A1 reactive marker × dsRNA/immune module coupling + astrocyte-specificity (Fisher Z) | *Figure 7* |
| `Script5_PD_vs_Control_Immune_Panels.R` | PD-vs-Control immune panel levels (lm, Wilcoxon, Hedges' g, interaction) | *Figure 7* |
| `Script6_Braak_Analysis.R` | Module scores vs Braak stage (partial Spearman + Jonckheere–Terpstra); null result | *Suppl. Fig 2* |
| `Script_S1_Module_Sensitivity_Analysis.R` | Leave-one-out, canonical-pathway substitution, permutation null | *Suppl. C* |
